Groky – Privacy Policy

Last updated: October 13, 2026

Groky is an iOS app and widget that displays your Grok usage from a JSON link you provide. We built it to collect as little as possible.

What Groky collects

Nothing. Groky has no account, no analytics, no ads, no tracking and no third-party SDKs. The developer receives no data from the app.

Data stored on your device

Groky stores on your iPhone only: the JSON URL you enter, the last usage data downloaded (percentage, reset date, tokens, credits, plan and account name if present in your file), and your language and appearance preferences. This data is kept in an App Group shared between the app and its widgets, never leaves your device except as described below, and is deleted when you use “Reset” in Settings or delete the app.

Network requests

The app and widgets download your JSON file from the URL you set (for example on GitHub or Google Drive) over HTTPS, about once an hour. That host may log standard request information (such as your IP address) under its own privacy policy. The “Set up bot” button opens a Grok Bot template link at x.ai, governed by xAI's privacy policy.

Your usage file and the Groky bot

The JSON file is created and published by a Grok Bot you set up and control, on the storage you choose. Anyone with its link can read it, so keep the link private. You can delete the file or the bot at any time.

Children

Groky is not directed at children and collects no personal data from anyone.

Changes

We may update this policy; the date above will change and the latest version will always be at this address.

Groky – Politique de confidentialité

Dernière mise à jour : 13 octobre 2026

Groky est une app iOS et un widget qui affichent votre usage Grok à partir d'un lien JSON que vous fournissez. Elle collecte le strict minimum.

Données collectées

Aucune. Pas de compte, pas d'analytics, pas de publicité, pas de suivi, aucun SDK tiers. Le développeur ne reçoit aucune donnée de l'app.

Données stockées sur l'appareil

Groky conserve uniquement sur votre iPhone : l'URL JSON saisie, les dernières données d'usage téléchargées (pourcentage, date de réinitialisation, tokens, crédits, plan et nom du compte s'ils figurent dans votre fichier) et vos préférences de langue et d'apparence. Ces données restent dans un App Group partagé entre l'app et ses widgets, et sont supprimées via « Réinitialiser » dans les Réglages ou en supprimant l'app.

Requêtes réseau

L'app et les widgets téléchargent votre fichier JSON depuis l'URL indiquée (par exemple GitHub ou Google Drive) en HTTPS, environ une fois par heure. Cet hébergeur peut journaliser des informations techniques (comme votre adresse IP) selon sa propre politique. Le bouton « Set up bot » ouvre un modèle Grok Bot sur x.ai, soumis à la politique de confidentialité de xAI.

Votre fichier d'usage et le bot Groky

Le fichier JSON est créé et publié par un Grok Bot que vous configurez et contrôlez, sur le stockage de votre choix. Toute personne ayant le lien peut le lire : gardez-le privé. Vous pouvez supprimer le fichier ou le bot à tout moment.

Enfants

Groky ne s'adresse pas aux enfants et ne collecte aucune donnée personnelle.

Modifications

Cette politique peut évoluer ; la date ci-dessus sera mise à jour et la dernière version restera à cette adresse.
